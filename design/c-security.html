Why this matters Haiku 4.5

Any person on the internet can read every document under /posts — no account, no token, just a fetch against your project. If those documents hold draft content, author emails, or anything not meant to be public, it is already public.

Scope the read to whoever should actually see it. For a published-posts collection that usually means checking a flag on the document itself: allow read: if resource.data.published == true;
